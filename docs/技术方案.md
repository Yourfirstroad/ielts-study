# 技术方案

React 19、TypeScript、Vite 8、React Router；沿用Foundry的按钮和Radix对话框、Lucide图标、Sonner通知、Tailwind工具。版本以package-lock.json为准。
业务入口 src/features/study：content.ts维护主题/词汇/官方来源，store.tsx维护Zod校验与持久化，pages.tsx提供页面。路由 src/app/app.tsx，样式 src/styles/tokens.css 与 study.css。
以北京时区计算日期；课程从profile.startDate按7日取模。页面每30秒检测跨日，今天视图跨午夜会更新；用户手选日期不自动跳转。
存储写入成功后才更新内存状态。损坏格式保留原始字符串，禁止覆盖；跨窗口变更阻止旧窗口继续写入。备份最大2MB，Zod校验后由用户确认替换。词汇学习记录写入实际当天，不随预览日期回填。
词汇按1/3/7/14/30日间隔进行简单自评复习，不宣称记忆效果保证。浏览器TTS不等于真人录音；官方听力播放在外部原站完成。
无业务账号/后端/云同步/自动抓取/AI评分/网页推送。本机开发地址127.0.0.1:5186；手机版面通过桌面Chrome模拟窄屏验证，尚无真机验证。
线上采用 Sites 私人静态托管，平台负责所有者访问验证。源码身份见 .openai/hosting.json；static.directory=dist，not_found_handling=single-page-application，支持 BrowserRouter 的深层链接刷新。平台登录不等于学习记录云同步，浏览器 localStorage 的原点隔离仍生效。发布不读取或上传用户 localStorage。
后续发布复用同一 project_id，通过官方 site-workflow 辅助脚本同步精确源码、构建、打包，再执行私人部署。短期凭据仅经隐藏 stdin 传递，不写入文件或终端参数。构建仍有单包略超500kB提示，gzip约167kB，不影响部署。
