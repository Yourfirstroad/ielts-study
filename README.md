## 可以做什么

- 今日学习：默认每日60分钟，词汇10、听力15、阅读15、口语10、写作10分钟。日期按北京时间，未来日期可预览但不能打卡或保存练习。
- 词汇复习：150词，按日期学习并有计划复习；中文、搭配、原创例句、浏览器朗读、词典链接、搜索及回忆模式。熟悉时按1/3/7/14/30天复习，不熟悉时次日复习；同一天不重复累进。
- 听说读写：官方听力入口和复盘笔记；30篇原创短文、90道判断题和解析，另保留旧起步版；口语准备/回答计时与笔记；A/G类Task 1和Task 2写作草稿自动保存及字数统计。
- 资料书架：IELTS、British Council、Cambridge原始来源；原创内容与官方材料清楚区分。
- 学习记录：完成任务、词汇活动、连续学习天数。不是成绩估算。
- 目标设置：分数、类型、月份、可选具体日期；A/G类草稿分别保存。
- 备份：导出JSON；导入先校验、展示摘要，再确认替换。格式错误或存储失败不会静默覆盖原数据。

## 当前内容范围

已预备 2026-10-28 至 2026-11-26 共 30 天课程：150 个精选词、300 词次（包含计划复习）、30 篇原创虚构短文与 90 道判断题、每日听说写任务。每天按北京时间 00:00 切换，打开首页即可学习当天内容；电脑关机不影响已发布课程的显示。课程并非每天现场联网生成。未来可以预览，往期可回看，范围外明确提示没有新课。

原 7 天起步版保留以便查看旧记录。官方链接需要联网，原站音频、题目、书籍内容不转载。听力样题按不同目标分轮复听，不声称有 30 套独立官方录音。完整模拟考试需要另留时间。

每晚 21:00 的原聊天日程读取同一份已发布课程，发送摘要与带日期的网站链接；需电脑开机且应用运行，可能延迟，不承诺离线通知。按已授权的维护流程，在未来课程不足 7 天时补充后续课程并验证后发布。维护规则见 docs/每日课程维护.md。网站没有独立邮件/手机推送、账号、学习进度云同步或自动评分。

课程唯一源文件：src/data/plan.json。网页构建与提醒共用校验和任务摘要函数。构建会发布 courses/plan.json；提醒程序使用 --published 核对线上与本地一致后才输出。示例：npm run daily:lesson -- 2026-10-28 --published。

## 托管维护

### GitHub Pages

`.github/workflows/pages.yml` 在推送 main 或手动触发时运行：安装锁定依赖、格式检查、构建、浏览器验证、发布。仓库 Settings → Pages → Source 应设为 GitHub Actions。工作流只上传 `dist-pages`，不上传源码目录、测试记录、凭据或用户学习备份。

`npm run build:pages` 使用 hash 路由（例如 `/ielts-study/#/vocabulary`），无需服务器路由回退，刷新和直接分享子页面均可用。资源路径默认 `/ielts-study/`；工作流从 GitHub Pages 获取实际路径。学习记录格式不变。`npm run test:pages` 会启动一个没有路由回退的静态服务器，检查电脑和手机尺寸下的子页面、刷新、打卡、草稿、无障碍跳转及访客隔离。

仓库公开不代表自动授予新的开源许可证；第三方许可见 THIRD_PARTY_NOTICES.md。本站不包含密钥、用户学习数据、官方付费书籍或真题全文。

### 现有 Sites

`.openai/hosting.json` 保留原站点标识。普通 `npm run build` 仍输出 `dist`、使用原来的 BrowserRouter 和单页应用回退；GitHub Pages 构建输出独立的 `dist-pages`，不会覆盖原构建。本次 GitHub 发布不重新部署现有 Sites。后续需要更新 Sites 时应先核对实际访问权限，使用相应的平台发布流程。
