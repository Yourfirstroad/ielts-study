# IELTS Study · 我的雅思学习站

为四级左右基础、目标 IELTS Academic 6.5、预计 2027 年 2 月考试的个人学习者制作。具体考试日期留空，可在目标设置修改。

## 在其他电脑使用

私人站点地址（首次发布成功后生效）：https://ielts-study-78a4ab06.steadylemon512.chatgpt.site

在其他电脑或手机的浏览器打开网址，按页面提示登录创建本站的同一个 ChatGPT 账号。网站由 Sites 托管，不需要让原电脑一直开机，也不需要在其他电脑安装 Node.js。本站没有改为公开分享；访问权限由托管平台控制。

**网页可跨电脑访问，但学习记录目前不自动同步。** 本机地址、线上地址、不同浏览器和不同电脑各有自己的记录。首次迁移：

1. 在原来的 http://127.0.0.1:5186/ 打开「目标设置」，导出学习备份。
2. 在新网址打开「目标设置」，选择导入该 JSON 文件。
3. 检查导入摘要，再确认替换。导入不是合并，会替换目标浏览器已有记录。

以后换电脑时同样导出并导入最新备份，建议固定一台设备为主要学习设备，避免来回覆盖。备份含个人草稿和学习记录，请自行妥善保存，不要上传到公开仓库。

源代码通过 Sites 专用源码仓库随发布保存，**并非 GitHub 仓库**。如需另存 GitHub，可在确定自己的仓库与访问权限后再推送；无需为了跨电脑访问而额外注册 GitHub。

手机尺寸已通过浏览器模拟验证。当前开发服务仅绑定本机 127.0.0.1；其他设备使用上方私人站点地址，而不是本机地址。

## 可以做什么

- 今日学习：默认每日60分钟，词汇10、听力15、阅读15、口语10、写作10分钟。日期按北京时间，未来日期可预览但不能打卡或保存练习。
- 词汇复习：70词，分7组主题；中文、搭配、原创例句、浏览器朗读、词典链接、搜索及回忆模式。熟悉时按1/3/7/14/30天复习，不熟悉时次日复习；同一天不重复累进。
- 听说读写：官方听力入口和复盘笔记；7篇原创短文、21道判断题和解析；口语准备/回答计时与笔记；A/G类Task 1和Task 2写作草稿自动保存及字数统计。
- 资料书架：IELTS、British Council、Cambridge原始来源；原创内容与官方材料清楚区分。
- 学习记录：完成任务、词汇活动、连续学习天数。不是成绩估算。
- 目标设置：分数、类型、月份、可选具体日期；A/G类草稿分别保存。
- 备份：导出JSON；导入先校验、展示摘要，再确认替换。格式错误或存储失败不会静默覆盖原数据。

## 当前内容范围

内置起步周7组主题、70词和对应微练习，从首次打开当天起按日安排，第二周起循环巩固。不是每天联网生成的新课程。官方链接需要联网，原站音频、题目、书籍内容不转载。

每晚21:00提醒由当前聊天的日程负责；网站尚未与日程同步学习进度或课程。本站不含独立邮件/手机推送、账号/云同步、自动批改、录音或估分。提供的写作字数统计只是空格分词计数。
